# Youtube Wissen Bibliothek

Wissen aus YouTube Videos, als Bücher je Thema mit Zusammenfassung, Kernaussagen, kurzen Zitaten mit Zeitmarke und Stichwörtern.

Online lesen: GitHub Pages dieses Repos, Einstieg `bibliothek/`.

Hinweis: Alle Inhalte geben wieder, was im jeweiligen Video gesagt wird. Sie sind keine geprüften Fakten. Unbelegte Thesen sind im Dashboard mit einer Einordnung markiert.

Neu bauen: `python3 -I werkzeuge/bibliothek_bauen.py`
